# ASHRAE Energy Analysis

## Projektübersicht

Analyse des Energieverbrauchs auf Basis des ASHRAE-Datensatzes.

Dieses Projekt verbindet folgende Bereiche:

- SQL / MySQL
- Python
- Statistik
- Machine Learning

## Forschungsfrage

Wie unterscheidet sich der Energieverbrauch nach Gebäudetyp, Zählertyp und Standort, und welche Zusammenhänge bestehen mit Gebäude- und Wetterinformationen?

## Projektstruktur

### 1. SQL / MySQL

- Aufbau der Datenbank
- Datenaufbereitung
- Datenqualitätsprüfung
- Verknüpfung der Tabellen
- SQL-Abfragen
- Analyse der Energiedaten

### 2. Python

- Datenaufbereitung
- Datenanalyse
- Datenvisualisierung

### 3. Statistik

- Deskriptive Statistik
- Durchschnittswerte
- Verteilungen
- Analyse von Zusammenhängen

### 4. Machine Learning

- Vorbereitung der Daten
- Entwicklung von Modellen
- Modellbewertung

## Datensatz

Das Projekt basiert auf dem ASHRAE Energy Prediction Datensatz.

## Ergebnisse

Die Ergebnisse und Visualisierungen werden im Laufe des Projekts ergänzt.
